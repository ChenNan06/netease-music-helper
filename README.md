# 网易云音乐 · 合一助手

在网易云网页版右下角挂一个悬浮面板，把**下载 / 歌词 / 封面 / 云盘 / 批量 / 播放**这些零散操作收在一处。

- 不修改网易云页面本身（只挂一个 48px 圆球）
- 零外部依赖（不需要任何 CDN 上的库）
- 不含账号数据、不上传任何东西（登录态只在你自己的浏览器里）

> 想先看界面：下载仓库里的 `output/面板预览-双击打开.html`，双击用浏览器打开即可（假数据，不联网）。

---

## 它解决什么问题

网易云网页版能做的事不少，但都是散的：下载要装第三方脚本、歌词得手动复制、批量下载是另一个脚本，两个脚本还会在同一页面上互相抢位置、各自往界面里塞自己的按钮。

本项目把这两个 MIT 脚本合并成一个面板。合并的原则是：**同一个功能如果两个脚本用了不同方法，两种都保留，按顺序自动降级**。

---

## 功能

| 分类 | 能力 |
|---|---|
| **单曲** | 下载（9 档音质，取不到就自动降档）、保存歌词（可合并翻译 / 罗马音）、保存封面、云盘快传、音源探测、复制 ID / 链接 |
| **列表** | 歌单 / 专辑 / 歌手 / 搜索页一键读取全部曲目；翻页（20~500 每页）、全量搜索、勾选、单首下载、批量下载、批量快传、导出 TXT / CSV / JSON |
| **载入** | 粘贴歌曲 ID 或链接（可多行混贴）→ 自动识别是单曲还是歌单/专辑/歌手 → 单首进卡片、多首进列表 |
| **播放** | 一键把载入的歌**替换进网易云播放列表**并播放；列表页可整批替换；⇄ 在「载入歌曲 / 详情页 / 正在播放」之间切换 |
| **云盘** | 快传（只报 md5 认领，秒完成零流量）、列表、导出、删除 |
| **工具** | 一键诊断（登录态 / 三路取链实际结果 / 云盘接口码 / 运行日志）、独立设置页 |

## 安装

1. 浏览器装一个用户脚本管理器：[Tampermonkey](https://www.tampermonkey.net/)（Edge / Chrome / Firefox 都有）或 Violentmonkey；
2. 下载脚本 → **到 [Releases](https://github.com/ChenNan06/netease-music-helper/releases/latest) 点最新的 `.user.js`**，文件会直接交给扩展安装；
3. 打开任意 `music.163.com` 页面 → 右下角出现红色圆球 → 点开就是面板。

> 从 raw 链接安装也可以，但部分网络环境下 `raw.githubusercontent.com` 会被阻断，所以推荐用 Releases。

**如果你之前装过那两个旧脚本，请先停用或删除**，否则三个脚本会同时挂在同一个页面上。

## 使用

### 面板结构

```
┌───────────────────────────────────────┐
│ ♪ 网易云助手 v1.4.1          ⚙    —   │  ⚙ 打开完整设置页
├───────────────────────────────────────┤
│ [封面] Valder Fields        ⏮  ▶  ⏭  │  卡片 = 当前操作对象
│        Tamas Wells · 无损  页面歌曲   │  徽章：音质 / 云盘 / VIP / 来源
│ ⇄ 正在播放  某首歌                    │  另有别的歌可切时才出现
├───────────────────────────────────────┤
│ ＋ 粘贴 ID 或链接载入…                │  载入条（点开变输入框）
├───────────────────────────────────────┤
│  单曲  │  列表  │  云盘  │  工具       │
├───────────────────────────────────────┤
│ 音质 [极高 ▾]         极高·自动降档·已登录│
│ [下载歌曲][保存歌词][保存封面][云盘快传] │
│ 查看歌词 · 音源探测 · 复制ID · 复制链接 │
├───────────────────────────────────────┤
│ ▬▬▬▬▬▬▬▬（有任务时才出现的进度条）      │
│ 当前：Valder Fields · 无损      42%    │
└───────────────────────────────────────┘
```

`▶` 的行为随上下文变化：卡片就是正在播放的那首时，它是播放/暂停；不是时，它是"用这首替换播放列表并播放"。

### 载入任意歌曲

点「＋ 粘贴 ID 或链接载入」，粘贴下面任意一种，回车或点「载入」：

```
186016
https://music.163.com/#/song?id=186016
https://music.163.com/playlist?id=3778678
```

单首直接进卡片；歌单/专辑/歌手链接会抓完整曲目进列表页。

### 批量下载

进入歌单/专辑/歌手/搜索页 → 面板「列表」→「读取当前页面列表」→ 搜索/翻页/勾选 → 「下载选中(N)」或「批量下载全部」。

不勾选时按**筛选后的全部**处理，确认框会写明范围。批量过程中可以「停止」。

### 云盘

云盘是网易云账号里的私人音乐仓库（不是硬盘）：歌放进去后**不受下架影响、任何登录该账号的设备都能听**。
「快传」是它的省事上传法——不上传音频，只提交文件的 md5，服务器上已有同一份就直接认领进你的云盘，秒完成、零流量。

### 诊断

歌曲下不动时，点「工具 → 运行诊断」：它会逐条打出登录态、三路取链各自的实际结果、云盘接口返回码，以及最近的日志。把这段日志贴进 issue 就能定位问题。

## 常见问题

**音质不对/显示"已降档"？**
音质受账号权限限制。面板会如实显示**实际拿到的那一档**，不会拿请求值冒充；VIP 曲目、母带等在无权限时会自动降到能取到的最高档。

**点了 ▶ 没反应？**
播放需要登录（网易云播放器本身要求登录态），并且会优先走页面自己的播放器，把这首歌塞进播放列表。如果页面播放器接口不可用，会退化成直连播放，此时 toast 会注明"网页播放条可能不跟随"。

**批量下载时浏览器让我允许下载多个文件？**
这是浏览器对同站多文件下载的默认拦截，点允许即可。

**提示"浏览器不允许脚本读取登录 cookie"？**
登录凭据是 HttpOnly 的，脚本读不到它——这不是错误。面板判断登录状态用的是接口，不依赖 cookie。

**和别的同时安装的网易云脚本冲突吗？**
本脚本不修改页面 DOM（只挂一个独立面板），也不劫持 `fetch`/`XHR`，理论上是隔离的；但多个脚本各自注入面板会重复显示，建议只留一个。

## 已知限制

1. 音质受账号权限限制，VIP/母带不保证能取到；
2. FLAC 不写内嵌标签，只旁挂 `.jpg` + `.lrc`（不动 FLAC 块结构，避免把文件写坏）；
3. 目录分级（`歌手/专辑/`）是否真建子目录取决于浏览器的下载设置；
4. 歌曲页结构或接口随时可能变，坏了先跑「诊断」；
5. 部分网络环境下 `raw.githubusercontent.com` 不可达，请用 Releases。

## 开发

```
src/parts/     源码分片（按加载顺序拼接）
  00-header.txt    Userscript 元数据
  10-core.js       常量 / 工具 / 设置存储 / weapi 加密
  20-api.js        请求层 / 接口 / 登录态
  30-engine.js     取链降级 / 下载 / 歌词 / ID3 / 云盘快传 / 列表抓取 / 解析输入
  40-ui.js         面板（Shadow DOM）
  45-actions.js    按钮 → 业务
  50-settings-page.js  独立设置页
  60-boot.js       当前对象追踪 / 启动
scripts/       构建、测试、取证脚本
docs/          设计说明（功能取舍、接口实测、交互逻辑）
output/        构建产物（开发版 / 发布版 / 面板预览）
```

```bash
python scripts/01-build.py            # 构建开发版（含排错入口）
python scripts/01-build.py --release  # 构建发布版（剥离开发期工具）
python scripts/02-verify.py           # 全量验证（435 项断言，需要联网的部分可加 --offline 跳过）
```

构建**不写入时间戳**：同样的源码永远得到同样的字节，便于核对 sha256。
