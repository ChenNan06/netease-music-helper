# 网易云音乐 · 合一助手（netease-music-helper）

> 把两个互相打架的油猴脚本**合并成一个**，统一到一个悬浮面板里。
> 合并自：RunningCheese「NetEase 网易云音乐助手」v2.1（23 KB）与 cinvin「网易云音乐:歌曲下载&转存云盘…」v4.4.6（396 KB），两者均为 MIT。
> 本会话日期：2026-11-25 ｜ 版本：**v1.4.0**

---

## 安装（任选一种）

| 方式 | 做法 |
|---|---|
| **直接装（推荐）** | 浏览器装好 Tampermonkey / Violentmonkey → 点这个链接：[网易云音乐-合一助手-v1.4.0.user.js](https://raw.githubusercontent.com/ChenNan06/netease-music-helper/main/output/%E7%BD%91%E6%98%93%E4%BA%91%E9%9F%B3%E4%B9%90-%E5%90%88%E4%B8%80%E5%8A%A9%E6%89%8B-v1.4.0.user.js) → 扩展会自动弹出安装页 |
| **从 Releases** | 到 [Releases](https://github.com/ChenNan06/netease-music-helper/releases) 下载 `.user.js`，拖进扩展窗口 |
| **自己构建** | `python scripts/01-build.py`（需要 Node 做语法检查），产物在 `output/` |

装完打开任意 `music.163.com` 页面，右下角出现红色圆球，点开即面板。
**旧的两个脚本请先停用或删除**，否则三者会同时挂在同一个页面上。

> 本项目不修改网易云页面、不收集任何数据、不含任何凭据；登录态只在你自己的浏览器里。

## v1.0.2 改了什么（你的第二轮反馈）

| 你的反馈 | 真因 | 现在 |
|---|---|---|
| **试听功能无法完整运行** | 三个硬伤叠在一起：① `audio.play()` 前面有 `await` 接口调用，**用户手势上下文丢失** → 浏览器静默拦截自动播放；② VIP/无版权曲目根本拿不到地址；③ 拿到的往往是 30 秒片段而不是完整音源 | **删掉试听器**（它和下载用的是同一个地址，等于"先播一遍再下一遍"，收益为零）。原位换成 **「音源探测」**：不播不下载，只把三路取链的真实结果摊开（可用/不可用、实际音质、走了哪条通道、文件大小），点一下就知道"这首歌为什么下不动" |
| **导出登录态：登录了还识别不了** | 这是我判断错的关键点：**`MUSIC_U` 是 HttpOnly cookie，`document.cookie` 永远读不到它**。所以旧代码既把"已登录"误判成"未登录"（面板徽章、云盘门禁全走错分支），也让导出必然失败 | ① 登录态改成**接口判定**（`/weapi/w/nuser/account/get` 有 `profile` = 已登录；实测匿名返回 `{code:200, profile:null}`，无副作用）；② 导出改走 **`GM_cookie`**（脚本管理器能读到 HttpOnly），读不到就明确告诉你"浏览器不让我读，请按 F12 手动复制"，不再假装"没登录" |
| **导出登录态不该出现在插件里** | 它只是给我排错用的 | 加 `DEV_TOOLS` 开关 + `#region dev-only` 标记：`python scripts\01-build.py` = 开发版（含），`--release` = **整段剥离**（连 `@grant GM_cookie` 一起删），并有 18 项构建门禁验证"剥干净且还能跑" |

顺带：面板「工具」页现在是 **账号 / 诊断 / 其他** 三段，登录状态行会显示 `已登录（昵称）· VIP`，旁边有「重新检测登录」。

## 合并时做了什么判断

详细对照表见 [`docs/功能对照与取舍.md`](docs/功能对照与取舍.md)。概要：

1. **重复的功能只留一份，但方法都保留**——你说的"同一功能两套代码，别二选一"这条是核心设计：
   下载地址现在是一条**三路取链、自动降级**的链（增强下载接口 → 试听播放接口 → 外链直取），前一个没拿到地址就自动试下一个，实测在匿名态下正是「①失败 → ②成功」。
2. **删掉的重复实现**：两套各自注入页面的按钮（3 个 + 十几个）、两套 toast / 两套设置弹窗（SweetAlert）、两套歌词解析器、两套取封面的 DOM 猜测逻辑。
3. **外部依赖全部去掉**：原脚本 `@require` 了 SweetAlert2 / ajax-hook / node-forge / mp3tag.js（4 个 CDN，共约 1.5 MB，断网就打不开）。现在加密用浏览器自带的 WebCrypto + BigInt 手写 RSA，ID3 标签自己写，面板自己画 —— **单文件、离线可用**。
4. **没搬过来的**（明确记录，不假装有）：云盘去重（`CloudDeduplication`）、本地文件批量打标签（`MusicFile`）、歌单按红心/评论排序、评论 IP 属地、指定 IP 发评论、按歌手打包快传（作者用远程 CDN 配置驱动，外部服务一挂就不能用）。这些是 v1.1 的候选，见取舍文档末尾。

**"真实"体现在哪**：

- **加密实现被服务器接受**：自写的 AES-CBC（WebCrypto）+ RSA（BigInt 裸模幂）拿真实 `music.163.com` 跑了 `/weapi/v3/song/detail` 与 `/weapi/song/lyric/v1`，都返回 `code=200` 且拿到「晴天」的曲目信息与歌词。
- **降级链是实测出来的，不是设计图**：匿名态下方法① `enhance/download/url/v1` 返回空地址 → 自动落到方法② `enhance/player/url/v1` → 拿到 `exhigh` 真实地址 → 实际拉到 **6.8 MB 真音频**，格式识别为 mp3。
- **面板不是"能渲染"就算**：在 jsdom 里真挂 Shadow DOM，依次点了下载 / 歌词 / 封面 / 快传 / 试听 / 四个标签页 / 列表抓取 / 导出 / 云盘 / 诊断，全部无异常，控制台 0 error。

## 已知限制（不掩饰）

1. **音质受账号权限限制**：VIP 曲目、`jymaster`/`hires` 等在无权限时会拿不到地址。脚本会**自动降档**并如实告诉你"实际下到的是哪一档"，不会冒充。想要最高音质就得登录且有对应会员。
2. **FLAC 不写内嵌标签**：MP3 会写入 ID3v2.4（标题/歌手/专辑/音轨/内嵌封面与歌词）；FLAC 只另存 `.jpg` + `.lrc` 旁挂文件。原因是不动 FLAC 的 VORBIS_COMMENT/PICTURE 块更安全，避免把文件写坏。
3. **批量下载可能弹一次"允许多文件下载"**：浏览器行为，点允许即可；带标签模式走内存 Blob，未开标签时优先用 `GM_download`。
4. **目录分级**：`歌手/专辑/` 会写进文件名前缀，Chrome 是否真的建子目录取决于下载设置（"下载前询问每个文件的保存位置"关掉时通常能建）。
5. **视觉我没法自动截图确认**：这台机器上 Chrome 157 / Edge 的 `--headless` 完全跑不起来（exit 0、零输出、零文件，加 `--no-sandbox`/`--single-process`/`-v` 都一样），所以配色与间距是**按网易云既有色值设计 + jsdom 结构断言 + 纯函数几何测试**保证的，最终观感请用 `output\面板预览-双击打开.html` 自己看一眼。
6. **接口会变**：网易云随时可能改接口或加风控。`诊断` 按钮会把三路取链各自的实际结果打出来，坏了先跑它。
7. **CDN 请求三条通道里哪条能用，取决于你的浏览器环境**：如果三条全失败，`日志/诊断` 里会逐条写出失败原因（管理器给的原因、fetch 的 HTTP 码），把它发我就能定位。

## 给排错用的「导出登录态」（**仅开发版**，一次即可，不用每次登录）

我这边**无法运行浏览器**（见限制 5），所以要复现"登录后才有的行为"（高音质、云盘快传、歌单全量），需要一次登录态样本：

1. 用**开发版**（`v1.0.2.user.js`，不是 `-release`）登录网易云；
2. 面板 →「工具」→ 点 **导出登录态**；
   - 走 `GM_cookie` 成功 → 直接得到 `ncmh-session.json`（同时复制到剪贴板）；
   - 若管理器不支持/被拒 → 会弹窗告诉你"浏览器不让我读 `MUSIC_U`（HttpOnly）"，并给出 **F12 → Application → Cookies → `https://music.163.com`** 手动复制的路径；
3. 把它放到 `netease-music-helper\tools\session.json`；
4. 之后我跑 `node scripts\10-loggedin-probe.mjs` 就能验证登录后的读取/取链/云盘，**不需要你反复登录**。

> 这个文件等同一次性登录凭据（含 `MUSIC_U`）。它只留在本机 `tools\` 下、不会进 `output\`、不会被上传；
> 想立即作废：在网页版点退出登录即可。脚本只调用**只读接口**（详情/歌词/取链/云盘列表/check），
> 不做 `import`/`del`/`match`，不会往你账号里写任何东西。
>
> **发布版（`-release`）里没有这个入口**，连 `@grant GM_cookie` 都被删掉——GitHub 上就是干净版本。

## 怎么改 / 怎么重建

```powershell
# 改代码：只改 src\parts\*.js，不要直接改 output 里的成品
python scripts\01-build.py     # 重新拼装 + node --check + 重新生成预览页
python scripts\02-verify.py    # 回归
```

分片职责：`10-core`（常量/工具/设置存储/weapi 加密）→ `20-api`（请求层与接口）→ `30-engine`（取链降级/下载/歌词/ID3/云盘快传/列表抓取）→ `40-ui`（面板）→ `45-actions`（按钮 → 业务）→ `50-settings-page`（设置页）→ `60-boot`（当前对象追踪/路由/启动）。

## 回滚

本项目不修改网易云、不改注册表、不装常驻进程。回滚 = 在 Tampermonkey 里删除/停用本脚本；设置存在 `music.163.com` 的 `localStorage`（键 `ncmh.settings.v1` / `ncmh.ui.v1`），清掉即恢复出厂。
